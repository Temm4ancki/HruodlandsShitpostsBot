# Hruodland's Shitposts Bot

Телеграм-бот для пересылки сообщений из телеграм-канала в Discord.
**Написан через Qodo**.

## Установка

1. Клонировать репозиторий
2. Установить зависимости:
   ```
   npm install
   ```
3. Создать `.env` файл на основе `.env.example`:
   ```
   cp .env.example .env
   ```
4. Заполнить `.env` файл своими данными
5. Скомпилировать TypeScript:
   ```
   npm run build
   ```

## Получение строки сессии Telegram

Для работы бота нужна строка сессии Telegram. Для её получения выполните:

```
npm run session
```

После этого скопируйте полученную строку в `.env` файл в поле `TELEGRAM_SESSION_STRING`.

## Запуск

```
npm start
```

Или можно запустить через BAT файл `Hruodland's Shitposts Bot.bat`

## Особенности

- Пересылает текстовые сообщения, фото и видео
- Группирует сообщения, отправленные с интервалом менее 3 секунд
- Конвертирует видео в формат MP4 перед отправкой
- Отслеживает уже обработанные сообщения, чтобы избежать дублирования
